# ارفع ملفات الـ PDF هنا

- كل ملف PDF = مشروع واحد في موقع الهويات (branding.designly-agency.com).
- **اسم الملف هو اسم المشروع في الموقع:**
  - `اسم العميل | اسم المشروع.pdf` ← مثلًا `قهوة مدار | هوية بصرية كاملة.pdf`
  - لو حطيت `★` في أول الاسم، المشروع هيظهر في أول الصفحة.
- بعد الرفع، GitHub بيحوّل الـ PDF لصور WebP عالية الجودة لوحده (حوالي دقيقة)، والموقع بيتحدث بعدها.
- لو عايز تمسح مشروع، امسح الـ PDF بتاعه.
